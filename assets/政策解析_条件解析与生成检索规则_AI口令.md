## 4. 第 3 步：生成检索规则（重点：loading + 流式）

### 4.1 刚进入时（Loading 态）



* 步骤条：①② 变绿勾，③ 蓝色当前。

* AI 助手对话框：spinner + "正在读取条件…"。

* 条件列表区**清空**，页面空白。

* 内容区**底部居中**只显示一颗绿色按钮：



```
&#x20; ✳  生成中
```



* 按钮样式：绿底 #52C41A、白字、圆角 6px、padding 8px 24px；左侧星号 / 菊花图标 CSS 旋转 1s / 圈匀速。

### 4.2 流式生成态（核心动效）

页面延迟 1 秒后，按下面顺序**逐条从顶部追加**卡片 + SQL 块，新条目淡入（opacity 0→1，translateY 8px→0，0.3s ease-out），上一条打完停顿 0.3 秒再出下一条。

#### 流程序列（按此顺序依次出现）

**第 1 条**：



* 卡片：`[必须满足]  名下无营业执照`

* 紧随其下的 SQL 代码块（单行，横向可滚动）：



```
SELECT insured\_identity FROM tenant\_650000\_data.ads\_insured\_info\_49 WHERE insured\_identity = '5...
```

**第 2 条**：



* 卡片：`[必须满足]  离校时间至签订就业见习协议的时间小于2年（以毕业证书签章日期为准）`

* 紧随其下的 SQL 代码块（多行）：



```
SELECT t1.id\_card

FROM tenant\_650000\_data.per\_account\_info\_49 t1

WHERE DATEDIFF(NOW(), CAST(t1.graduate\_time AS DATE)) < 730

&#x20; AND t1.id\_card = 'query\_id'

UNION ALL

SELECT t2.id\_card

FROM tenant\_650000\_data.edi\_ads\_jy\_subsidy\_detail\_49 t2

WHERE DATEDIFF(NOW(), t2.graduate\_time) < 730

&#x20; AND t2.id\_card = 'query\_id'
```

### 4.3 SQL 代码块样式



* 背景深炭灰 #1E1E1E，圆角 8px，padding 16px 20px，等宽字体 Consolas / Menlo，13px，行高 1.6。

* 语法高亮：


  * SQL 关键字（SELECT / FROM / WHERE / AND / UNION ALL / CAST / AS / DATE）：白色加粗

  * 函数名（NOW / DATEDIFF）：浅蓝色 #4EC9B0

  * 库表名（tenant\_650000\_data.\*、per\_account\_info\_49、edi\_ads\_jy\_subsidy\_detail\_49）：橙色 #CE9178

  * 字符串字面量（'5...'、'query\_id'）：粉红色 #D16969

  * 数字（730）：浅紫 #B8D7A3

* 内容过宽时横向滚动（`overflow-x:auto`），不自动换行。

* 打字机效果：SQL 字符按约 24 字符 / 秒逐字显现，光标可省略。

### 4.4 完成态

两条规则 + SQL 全部打完后：



* AI 助手对话框文字变为 "已完成检索规则生成"（spinner 消失）。

* 底部绿色 "生成中" 按钮**平滑过渡**（背景色 0.3s 渐变）为品牌蓝 **"完成"** 按钮，左侧图标从旋转菊花变为对勾或直接去掉。

* 步骤条 ③ 由蓝色当前变绿色 ✓。

* 按钮排列：**上一步**（白底灰边，居左）+ **完成**（品牌蓝白字，居右）。

* 点 "完成" 弹 Toast"政策创建成功"。
