# 政策主动服务功能设计口令文档

> 适用产品：AI 运营平台 —— 智能匹配推荐 / 政策找人模块
> 文档用途：作为前端页面搭建、AI 生成页面、产品开发的完整口令（Prompt），照着本文档即可 1:1 还原页面与全部交互。
> 设计风格：浅色后台管理系统风格，主色为品牌蓝（#3370FF 类），卡片白底、圆角、轻阴影，左侧固定图标 + 文字二级导航，顶部为一级导航与用户信息。

---

## 一、整体布局

### 1.1 页面骨架

```
┌─────────────────────────────────────────────────────────────────┐
│  顶部栏：[AI运营平台 Logo]                    用户头像 aks202607 ▾ │
├──────────┬──────────────────────────────────────────────────────┤
│ 左侧一级 │  二级 Tab 导航（5 个图标按钮，纵向排列）                │
│ 导航     │ ┌──────────────────────────────────────────────────┐ │
│          │ │  AI政策库   （当前选中项高亮蓝色方块底）             │ │
│ AI应用中心│ │  智能解析                                           │ │
│ 智能匹配推│ │  政策找人                                           │ │
│  荐      │ │  推送记录                                           │ │
│ 政策找人 │ │  标注                                               │ │
│          │ └──────────────────────────────────────────────────┘ │
│          │  右侧主内容区：根据选中的二级 Tab 切换对应页面          │
└──────────┴──────────────────────────────────────────────────────┘
```

### 1.2 一级导航（左侧最左列）

- **AI应用中心**：房子图标，普通态。
- **智能匹配推荐**：图标按钮，展开后高亮显示当前子项「政策找人」（左侧带蓝色竖条指示）。

### 1.3 二级菜单（5 个 Tab，支持切换）

| 序号 | 菜单名   | 图标含义     | 页面职责                                   |
| ---- | -------- | ------------ | ------------------------------------------ |
| 1    | AI政策库 | 书签图标     | 政策分类树 + 政策卡片列表，政策的增删配置   |
| 2    | 政策解析 | 文档图标     | 三步向导：政策上传 → 条件解析 → 生成检索规则 |
| 3    | 政策找人 | 人形定位图标 | 匹配批次列表，执行匹配、推送、导出          |
| 4    | 推送记录 | 书签勾选图标 | 历史推送任务记录与详情查看                  |
| 5    | 标注     | 书签图标     | 数据字段解释（标注字典）的维护              |

**Tab 交互要求**：
- 点击任意二级菜单，主内容区立即切换为对应页面，页面状态独立保留（切回不丢失筛选条件与滚动位置）。
- 当前选中项：图标 + 文字变为品牌蓝，外层带浅蓝圆角方块背景。
- 未选中项：图标 + 文字为灰色。

## 二、AI政策库（Tab 1）

### 2.1 页面结构

采用左右分栏布局。

#### 左侧：政策分类树面板

- 面板标题：**政策分类**，标题右侧带「菜单/折叠」图标按钮。
- 顶部搜索框：占位文字「输入关键字进行过滤」，实时过滤下方树节点。
- 树形分类数据（可展开/折叠，节点前带三角箭头）：

```
政策分类
├─ 一、就业创业补贴
│   ├─ 1.就业见习补贴
│   └─ 2.社会保险补贴
│       ├─ (1) 高校毕业生社会保险补贴
│       └─ (2) 就业困难人员社会保险补贴
├─ 二、培训服务补贴
│   └─ 1.外出务工奖励补助
├─ 三、求职帮扶补贴
│   ├─ 1.一次性求职补贴
│   └─ 2.公益性岗位补贴及社会保险补贴
├─ 四、创业担保贷款
└─ 五、纺织服装四项补贴
    ├─ 1.新招录新疆籍职工补贴
    ├─ 2.纺织服装个人社保补贴
    └─ 3.南疆人才引进补贴
```

- 点击树节点：右侧政策卡片列表按该分类过滤。

#### 右侧：筛选栏 + 政策卡片区

**筛选栏（一行排布）**：

| 控件     | 类型     | 占位/选项           | 说明             |
| -------- | -------- | ------------------- | ---------------- |
| 政策名称 | 输入框   | 请输入              | 模糊搜索政策名   |
| 对象     | 下拉选择 | 请选择              | 选项：个人 / 企业 |
| 搜索     | 按钮     | 品牌蓝填充          | 执行查询         |
| 重置     | 按钮     | 灰色填充            | 清空全部筛选条件 |
| 智能解析 | 按钮     | 品牌蓝填充          | 跳转「政策解析」Tab |

### 2.2 政策卡片

- 三列等宽网格布局，卡片白底、圆角、内边距适中。
- 卡片内容（自上而下）：
  1. **政策名称**（加粗，如：高校毕业生灵活就业社保补贴）
  2. 对象：个人 / 企业
  3. 数量：X 条
  4. 创建时间：YYYY-MM-DD HH:mm:ss
  5. 底部操作行（右对齐，文字按钮）：
     - **发放记录**（绿色文字）
     - **配置**（蓝色文字）
     - **删除**（红色文字，点击弹二次确认框：「确认删除该政策？此操作不可恢复」，确认后删除卡片并刷新列表）

### 2.3 分页器（底部居中）

- 左侧：共 X 条
- 每页条数下拉：20条/页（可切 10/20/50）
- 页码按钮：上一页 < 当前页（蓝色方块高亮）下一页 >
- 前往 [ 1 ] 页

### 2.4 「配置」弹窗 —— 规则配置

点击卡片「配置」按钮，右侧滑出/居中弹出**规则配置**弹窗（右上角 × 关闭）。

**表单字段**：

| 字段       | 必填 | 控件类型   | 说明                                                     |
| ---------- | ---- | ---------- | -------------------------------------------------------- |
| 政策名称   | 是   | 输入框     | 自动带入当前政策名，可改                                 |
| 政策分类   | 否   | 下拉选择   | 级联显示左侧分类树路径，如「一、就业创业补贴/2.社会保险补贴/(1)…」 |
| 政策条件   | 是   | 多行文本域 | 如：补贴对象：参加灵活就业的离校2年内未就业高校毕业生；补贴条件：实现灵活就业并缴纳社会保险费 |
| 补贴对象   | 是   | 下拉选择   | 个人 / 企业                                              |
| 政策文件   | 否   | 上传按钮   | 蓝色「上传」按钮；上传成功后显示文件条目：[文件图标] 文件名… + 绿色圆形对勾图标 |

**匹配规则区块**：
- 区块标题：**匹配规则**，右侧「添加规则」蓝色按钮。
- 每条规则卡片包含：
  - 规则类型下拉（默认「必须满足」，可切「可达条件」等）
  - 条件描述输入框（如：个人状态生存状态为"生存"；人员为2024年届和2025年届的高校毕业生）
  - 「已生效」绿色小标签
  - 红色圆形删除按钮（垃圾桶），点击删除该条规则
- 规则卡片右侧悬浮一个圆形女性头像图标（AI 助手入口，点击可唤出 AI 辅助生成规则描述）。

**弹窗底部按钮**：
- 确定（品牌蓝填充）：保存规则，关闭弹窗，卡片数据刷新。
- 取消（白底灰边）：放弃修改并关闭。

## 三、政策解析（Tab 2，智能解析）

### 3.1 三步流程向导

页面顶部横向步骤条，三个圆形序号节点以横线连接：

```
① 政策上传 ────── ② 条件解析 ────── ③ 生成检索规则
   (蓝色高亮)        (灰色)             (灰色)
```

- 当前步骤节点为蓝色实心圆 + 蓝色文字；未到达节点为灰色空心圆 + 灰色文字。
- 点击已完成步骤可回退编辑。

### 3.2 第 1 步：政策上传

页面顶部提示语：

> 请上传补贴类的政策依据，将自动解析并精准匹配适用对象，助力政策主动兑现。

**表单字段**：

| 字段       | 必填 | 控件类型       | 占位文字               |
| ---------- | ---- | -------------- | ---------------------- |
| 政策名称   | 是   | 输入框         | 请输入政策名称         |
| 对象       | 是   | 单选框         | ○ 个人    ○ 企业       |
| 政策分类   | 否   | 下拉选择       | 请选择                 |
| 政策条件   | 是   | 多行文本域     | 请输入政策条件         |
| 政策文件   | 否   | 上传按钮       | 蓝色「上传」按钮       |

**底部按钮**：
- **下一步**（品牌蓝填充，居中偏右）：表单校验通过后进入第 2 步；未填必填项时对应字段红字提示并阻止前进。

### 3.3 第 2 步：条件解析（流程占位）

- 步骤条高亮第 2 步。
- 页面展示 AI 自动解析结果：将政策文件中的补贴对象、补贴条件拆解为结构化条件条目列表，每条可编辑文本、可删除、可手动补充。
- 底部按钮：**上一步**（灰）、**下一步**（蓝）。

### 3.4 第 3 步：生成检索规则

- 步骤条高亮第 3 步。
- 展示 AI 生成的匹配规则（与「规则配置」弹窗中的规则结构一致）：规则类型下拉 + 条件描述输入 + 已生效标签 + 删除按钮。
- 支持「添加规则」。
- 底部按钮：**上一步**（灰）、**完成**（蓝）。
- 完成后自动保存政策，跳转回「AI政策库」Tab 并提示「政策创建成功」。

## 五、推送记录（Tab 4）

### 5.1 页面结构

**筛选栏**：对象下拉（请选择）、政策名称输入框（请输入）、搜索（蓝）、重置（灰），右上角对齐。

**表格列**：

| 列名     | 说明                                   |
| -------- | -------------------------------------- |
| 序号     | 1、2…                                  |
| 政策名称 | 如：单位吸纳就业困难人员社会保险补贴   |
| 对象     | 企业 / 个人                            |
| 推送数量 | 整数，如 142、3829                     |

### 7.3 空态与加载态

- 姓名：保留姓氏 + * + 名尾字（如 李*明）。

- 手机号：保留前 3 位与后 4 位，中间 4 位以 * 代替。

## 八、业务闭环说明（口令速记）

1. **建政策**：「政策解析」上传政策文件 → AI 解析条件 → 生成检索规则 → 完成后入「AI政策库」。
2. **配规则**：在 AI政策库 点「配置」，维护补贴对象、政策条件、匹配规则（必须满足/可达条件），上传政策文件。
3. **找对象**：在「政策找人」点「新增」发起匹配批次，AI 按规则跑批，产出匹配人数。
4. **看明细**：点「匹配结果」查看逐人满足/不满足规则的原因明细。
5. **做推送**：点「推送」，二次筛选人群、AI 撰写话术、确认发送。
6. **查记录**：「推送记录」里查看每次推送的数量、状态与详情。
7. **养词典**：「标注」Tab 维护数据字段解释（字段名 + 枚举解释），供 AI 规则生成与匹配时召回使用。

> 以上即为政策主动服务功能的完整页面、字段、按钮、弹窗与交互口令，可直接用于页面还原或 AI 生成实现。
